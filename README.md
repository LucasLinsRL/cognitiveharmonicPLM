🧠 Cognitive Harmony – PLM

Projeto de TCC – ETEC (INFONET)

📌 Sobre o projeto

O Cognitive Harmony (PLM – Program Logic Men) é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) da ETEC, com foco em conteúdos informativos e educativos voltados para pessoas com dificuldades cognitivas, como:

TDAH (Transtorno do Déficit de Atenção com Hiperatividade)

Cognição

Inteligência emocional

Habilidades socioemocionais

A proposta do projeto é informar, conscientizar e facilitar o acesso ao conhecimento, utilizando uma linguagem clara, visual acessível e uma navegação simples, pensando principalmente em usuários que podem ter dificuldades de foco, organização ou processamento de informações.

🎯 Objetivo

Criar um site informativo que:

Apresente conteúdos confiáveis sobre cognição e saúde socioemocional

Seja acessível, responsivo e intuitivo

Utilize recursos visuais para melhorar a compreensão

Sirva como apoio educacional para estudantes e interessados no tema

🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

HTML5 – Estruturação do site

CSS3 – Estilização, layout e responsividade

JavaScript – Interatividade e funcionalidades do site


🎨 Design e mídia

Todo o design visual, imagens, elementos gráficos e vídeos foram criados e editados manualmente por mim, utilizando o Canva.

Layout pensado para ser limpo, organizado e acessível.


📚 Processo de desenvolvimento

O desenvolvimento do projeto passou por várias etapas ao longo do ano letivo:

Início sem um tema definido

Pesquisas sobre possíveis áreas de atuação

Discussões em grupo e validações com a professora

Criação de apresentações parciais

Refinamento do tema até chegar à proposta final

Desenvolvimento contínuo do site

Apresentação final do TCC

Como a própria professora comentou durante o processo:

“O TCC é como um filho: você gera a ideia, acompanha o crescimento durante o ano e, no final, vê ele pronto.”

Esse projeto representa exatamente isso: evolução, aprendizado e prática real.
